# Gem Drop Puzzle

シンプルな **Match-3 パズルゲーム** です。モバイル縦持ちでも動作し、将来的に iOS (App Store) へパッケージしやすい構成（HTML/CSS/JS）にしています。

## 新機能

- 制限時間（90秒） + 手数（30手）のハイブリッドルール
- ベストスコア保存（`localStorage`）
- ヒント機能（次の有効手を黄色枠で表示）
- 手詰まり時の自動シャッフル
- 手動シャッフルボタン（1手消費）

## 遊び方

- 隣り合うジェムをタップして入れ替える
- 3つ以上同じ色を揃えると消える
- 連鎖が続くほどスコア倍率アップ
- 手数または時間が尽きるとゲーム終了

## 起動

ローカルサーバーで開いてください。

```bash
python3 -m http.server 8080
# http://localhost:8080 をブラウザで開く
```

## アセット方針

今回のジェム画像（`assets/gem-*.svg`）はこのリポジトリ内で自作したオリジナル SVG です。商用利用前提で、第三者ライセンスに依存しない最小構成にしてあります。

App Store 向けにクオリティを上げる場合は、以下のように置換可能です。

- UI: 独自デザインのボタン/パネル画像
- BGM/SE: ライセンス明記済み素材 or 外注制作
- アイコン: 1024x1024 の専用アプリアイコン
- スクリーンショット: 6.7" / 6.5" / 5.5" など審査要件サイズ

## iOS 向けの次ステップ（概要）

1. Capacitor / Cordova で Web アプリをラップ
2. Xcode で署名設定
3. App Store Connect に素材・説明文を登録
4. TestFlight で実機検証
